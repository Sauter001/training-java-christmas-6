# 구현할 기능 목록

## 1. 입력 기능

### 1.1 방문 날짜 입력
- [ ] 방문 날짜를 입력받는다.
- [ ] 입력값이 1 이상 31 이하의 숫자인지 검증한다.
- [ ] 유효하지 않은 날짜일 경우 `[ERROR] 유효하지 않은 날짜입니다. 다시 입력해 주세요.` 출력 후 재입력받는다.

### 1.2 주문 메뉴 입력
- [ ] 주문할 메뉴와 개수를 입력받는다. (형식: `메뉴명-개수,메뉴명-개수`)
- [ ] 입력 형식이 올바른지 검증한다.
- [ ] 유효하지 않은 주문일 경우 `[ERROR] 유효하지 않은 주문입니다. 다시 입력해 주세요.` 출력 후 재입력받는다.

## 2. 주문 유효성 검증

### 2.1 메뉴 검증
- [ ] 입력한 메뉴가 메뉴판에 존재하는지 확인한다.
- [ ] 메뉴의 개수가 1 이상의 숫자인지 확인한다.
- [ ] 중복된 메뉴가 입력되지 않았는지 확인한다.

### 2.2 주문 제약 조건 검증
- [ ] 음료만 주문했는지 확인한다.
- [ ] 메뉴의 총 개수가 20개 이하인지 확인한다.
- [ ] 총 주문 금액이 10,000원 이상인지 확인한다.

## 3. 할인 및 혜택 계산

### 3.1 크리스마스 디데이 할인
- [ ] 방문 날짜가 1일~25일 사이인지 확인한다.
- [ ] 1,000원에서 시작하여 하루마다 100원씩 증가하는 할인 금액을 계산한다.
  - 12월 1일: 1,000원
  - 12월 2일: 1,100원
  - 12월 25일: 3,400원

### 3.2 평일 할인 (일요일~목요일)
- [ ] 방문 날짜가 평일인지 확인한다.
- [ ] 디저트 메뉴의 개수를 확인한다.
- [ ] 디저트 메뉴 1개당 2,023원 할인을 계산한다.

### 3.3 주말 할인 (금요일, 토요일)
- [ ] 방문 날짜가 주말인지 확인한다.
- [ ] 메인 메뉴의 개수를 확인한다.
- [ ] 메인 메뉴 1개당 2,023원 할인을 계산한다.

### 3.4 특별 할인
- [ ] 방문 날짜에 별이 있는지 확인한다. (일요일, 25일)
- [ ] 특별 할인 대상일 경우 1,000원 할인을 적용한다.

### 3.5 증정 이벤트
- [ ] 할인 전 총주문 금액이 120,000원 이상인지 확인한다.
- [ ] 조건 충족 시 샴페인 1개를 증정한다.
- [ ] 증정 메뉴의 가격(25,000원)을 총혜택 금액에 포함한다.

### 3.6 총혜택 금액 계산
- [ ] 모든 할인 금액의 합계를 계산한다.
- [ ] 증정 메뉴의 가격을 더하여 총혜택 금액을 계산한다.
- [ ] 총혜택 금액 = 할인 금액의 합계 + 증정 메뉴의 가격

### 3.7 할인 후 예상 결제 금액 계산
- [ ] 할인 전 총주문 금액에서 할인 금액을 뺀다.
- [ ] 할인 후 예상 결제 금액 = 할인 전 총주문 금액 - 할인 금액
- [ ] 증정 메뉴의 가격은 제외한다.

## 4. 이벤트 배지 부여

- [ ] 총혜택 금액에 따라 배지를 부여한다.
  - 5,000원 이상: 별
  - 10,000원 이상: 트리
  - 20,000원 이상: 산타
- [ ] 해당 사항이 없을 경우 "없음"을 표시한다.

## 5. 출력 기능

### 5.1 주문 메뉴 출력
- [ ] 주문한 메뉴와 개수를 출력한다.
- [ ] 형식: `메뉴명 개수개`

### 5.2 할인 전 총주문 금액 출력
- [ ] 주문한 모든 메뉴의 가격 합계를 출력한다.
- [ ] 형식: `###,###원`

### 5.3 증정 메뉴 출력
- [ ] 증정 이벤트 해당 시 `샴페인 1개`를 출력한다.
- [ ] 해당하지 않을 경우 `없음`을 출력한다.

### 5.4 혜택 내역 출력
- [ ] 적용된 이벤트와 할인 금액을 출력한다.
- [ ] 형식: `이벤트명: -###,###원`
- [ ] 적용된 이벤트가 없을 경우 `없음`을 출력한다.

### 5.5 총혜택 금액 출력
- [ ] 총혜택 금액을 출력한다.
- [ ] 형식: `-###,###원`
- [ ] 혜택이 없을 경우 `0원`을 출력한다.

### 5.6 할인 후 예상 결제 금액 출력
- [ ] 할인 후 예상 결제 금액을 출력한다.
- [ ] 형식: `###,###원`

### 5.7 12월 이벤트 배지 출력
- [ ] 부여된 배지를 출력한다.
- [ ] 배지가 없을 경우 `없음`을 출력한다.

## 6. 도메인 모델

### 6.1 메뉴
- [ ] 메뉴 이름, 가격, 카테고리(애피타이저, 메인, 디저트, 음료)를 관리한다.
- [ ] 전체 메뉴판 정보를 제공한다.

### 6.2 주문
- [ ] 메뉴와 수량을 관리한다.
- [ ] 총 주문 금액을 계산한다.
- [ ] 주문 유효성을 검증한다.

### 6.3 날짜
- [ ] 방문 날짜 정보를 관리한다.
- [ ] 평일/주말 여부를 판단한다.
- [ ] 특별 할인 대상 여부를 판단한다.

### 6.4 이벤트
- [ ] 각 이벤트별 할인 금액을 계산한다.
- [ ] 이벤트 적용 조건을 확인한다.
- [ ] 총혜택 금액을 계산한다.

### 6.5 배지
- [ ] 총혜택 금액에 따라 적절한 배지를 반환한다.

## 7. 예외 처리

- [ ] 모든 예외는 `IllegalArgumentException`으로 처리한다.
- [ ] 에러 메시지는 `[ERROR]`로 시작한다.
- [ ] 예외 발생 시 해당 부분부터 다시 입력받는다.
